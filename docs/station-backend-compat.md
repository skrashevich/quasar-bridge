# Станция обходит WSS после загрузки облачных настроек

На проверенной Станции 2 (Buildroot 2020.02.1, BUILD_ID 4793639783)
изменения `aliced.uniProxyUrl` и `uniProxyQuicUrl` в локальном `quasar.cfg`
оказались недостаточны. Алиса отвечала напрямую, а у Bridge оставались нулевые
счётчики кадров. Облачный `get_sync_info` возвращал предпочтение QUIC.

Для этой ситуации добавлен необязательный `yandex_backend_compat`:

```json
{
  "yandex_backend_compat": true
}
```

Он требует настроенного TLS. На существующем HTTPS listener появляется
`/yandex-backend/`, который пересылает запросы только на `https://quasar.yandex.net`
с проверкой сертификата. Соединение с Яндексом прямое, независимо от HTTP_PROXY.
В успешном GET `/get_sync_info` меняются два поля
`config.system_config.voiceDialogSettings`: `uniProxyPreferQuic=false` и
`uniProxyQuicUrl=""`. Другие поля сохраняются; неизвестная структура ответа
передаётся без изменений.

На колонке, помимо WSS URL Bridge и пустого QUIC URL, нужно задать
`common.backendUrl` равным `https://<bridge-host>:<port>/yandex-backend`
(без завершающего слеша). Используйте имя или IP из SAN сертификата сервера.
CA Bridge должен быть добавлен в доверенный bundle колонки. Порядок резервного
копирования, применения конфигурации и перезагрузки описан в [руководстве](guide.md).
Не подменяйте всю конфигурацию файлом от другой колонки.

После перезагрузки проверьте обычный вопрос Алисе и `/healthz`: должны расти
`client_frames`, `server_frames`, а `yandex_backend_compat.rewritten` подтверждает
обработку облачной конфигурации. Эти счётчики не доказывают работу всех функций.

Bridge становится посредником и для backend API: при его недоступности колонка
теряет этот путь. Для отката сначала восстановите исходный `common.backendUrl`
и перезагрузите колонку, затем отключите серверный флаг. Сохраните исходные файлы
и CA bundle до изменения. Авторизация и cookies пересылаются официальному backend;
прокси не записывает их содержимое в журнал.

На указанной Станции 2 проверены соединение через Bridge и обычные ответы Алисы.
Работа нескольких колонок и других версий прошивки отдельно не проверялась.
